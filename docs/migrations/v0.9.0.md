# Migration guide — v0.9.0

`v0.9.0` carves the lean `core/` sub-module (ADR-0017), relicenses the
project to EUPL-1.2 (ADR-0018), and adopts praetor governance (ADR-0019).
The Go toolchain floor moves to **1.27.0** and every dependency is bumped.

## Breaking: ten packages moved to `github.com/golusoris/golusoris/core/…`

| Before | After |
|---|---|
| `github.com/golusoris/golusoris/config` | `github.com/golusoris/golusoris/core/config` |
| `github.com/golusoris/golusoris/log` | `github.com/golusoris/golusoris/core/log` |
| `github.com/golusoris/golusoris/clock` | `github.com/golusoris/golusoris/core/clock` |
| `github.com/golusoris/golusoris/errors` | `github.com/golusoris/golusoris/core/errors` |
| `github.com/golusoris/golusoris/crypto` | `github.com/golusoris/golusoris/core/crypto` |
| `github.com/golusoris/golusoris/id` | `github.com/golusoris/golusoris/core/id` |
| `github.com/golusoris/golusoris/validate` | `github.com/golusoris/golusoris/core/validate` |
| `github.com/golusoris/golusoris/version` | `github.com/golusoris/golusoris/core/version` |
| `github.com/golusoris/golusoris/clikit` | `github.com/golusoris/golusoris/core/clikit` |
| `github.com/golusoris/golusoris/mcp` | `github.com/golusoris/golusoris/core/mcp` |

`clikit/tui` keeps its path (`github.com/golusoris/golusoris/clikit/tui`).
Package names and APIs are unchanged; only the import path moves.

**Before:**

```go
import (
    "github.com/golusoris/golusoris/config"
    "github.com/golusoris/golusoris/log"
)
```

**After:**

```go
import (
    "github.com/golusoris/golusoris/core/config"
    "github.com/golusoris/golusoris/core/log"
)
```

### Codemod

`golusoris bump v0.9.0` applies the rewrite. Manually, with the shared AST
rewriter (no string replacement — aliases and comments survive):

```go
mapping := map[string]string{
    "github.com/golusoris/golusoris/config":   "github.com/golusoris/golusoris/core/config",
    "github.com/golusoris/golusoris/log":      "github.com/golusoris/golusoris/core/log",
    "github.com/golusoris/golusoris/clock":    "github.com/golusoris/golusoris/core/clock",
    "github.com/golusoris/golusoris/errors":   "github.com/golusoris/golusoris/core/errors",
    "github.com/golusoris/golusoris/crypto":   "github.com/golusoris/golusoris/core/crypto",
    "github.com/golusoris/golusoris/id":       "github.com/golusoris/golusoris/core/id",
    "github.com/golusoris/golusoris/validate": "github.com/golusoris/golusoris/core/validate",
    "github.com/golusoris/golusoris/version":  "github.com/golusoris/golusoris/core/version",
    "github.com/golusoris/golusoris/clikit":   "github.com/golusoris/golusoris/core/clikit",
    "github.com/golusoris/golusoris/mcp":      "github.com/golusoris/golusoris/core/mcp",
}
_ = astx.Walk(ctx, ".", astx.WalkOptions{IncludeTests: true}, func(p string) error {
    _, err := astx.RewriteImportsFile(p, mapping)
    return err
})
```

Then fix the one exception (`core/clikit/tui` → `clikit/tui`) and run:

```sh
go get github.com/golusoris/golusoris/core@v0.9.0 github.com/golusoris/golusoris@v0.9.0
go mod tidy
```

Apps that only use core packages can drop the root requirement entirely.

## Breaking: Go 1.27.0 toolchain floor

`go.mod` in every module declares `go 1.27.0`. Bump your toolchain (or rely
on `GOTOOLCHAIN=auto`).

## Changed: licence

Code is EUPL-1.2 (was MIT); documentation CC-BY-SA-4.0. See
[LICENSING.md](https://github.com/golusoris/golusoris/blob/main/LICENSING.md). Releases ≤ v0.8.0 remain MIT.

## Changed: dependency bump

All direct and indirect dependencies were fast-forwarded (`go get -u -t`)
across root, core, and the 20 sub-modules. Notable majors already in use:
k8s.io/* v0.37, controller-runtime v0.25, casbin v3, riverui v0.19. If your
app pins older k8s libraries, align them: `kube-openapi` must match the
version required by `k8s.io/apimachinery` (mixing pulls both
`structured-merge-diff/v6` and `/v7` and fails to compile).

## Added

- `core/codec/yaml` — fleet YAML codec (strict, bounded, atomic writes).
- `core/crypto/receipt` — Ed25519 Exit-0 execution receipts (fx `Module`, config `crypto.receipt.seed`).
- `core/gitx`, `core/gitx/worktree` — bounded git runner + per-task worktrees.
- `core/astx` — bounded source walker, AST import rewriter, function metrics, go.mod reader.
- `core/capabilities` + root `capabilities.yaml` — the machine-readable capability contract.
- `db/sqlite` — modernc.org/sqlite fx module (`db.sqlite.*`).
- Governance: `.standards.yaml`, HISS-16 baseline, compiled vendor agent context, `make verify-all`.
