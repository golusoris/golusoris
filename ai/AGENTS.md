# ai

Artificial intelligence, numerical optimization, and machine learning packages.

## Packages

- `ai/llm/` — unified Chat, Stream, and Embed interface (Anthropic, OpenAI, Ollama).
- `ai/tiny/` — task-specific model trainer/predictor orchestration and container runners.
- `ai/tpe/` — Tree-structured Parzen Estimator for black-box hyperparameter search.
- `ai/vector/` — vector embeddings and similarity search on PostgreSQL pgvector.
